# OEPS Scanner v0.1.0

First Windows x64 release of the Data Matrix scanner.

## Install

Download **OEPS.Scanner-0.1.0-setup-win-x64.msi**. It installs the server and test client with separate desktop and Start menu shortcuts. Both run without installing Python, .NET or developer tools separately. Settings are kept per user and preserved during updates.

The launcher offers newer releases at startup and retains a working version for recovery. Both apps display their version at the bottom right and show an update notification when a newer release is available. Close both apps before updating; an offline station continues with its installed version.

## Scanning

- Data Matrix-only decoding, including multiple codes in one camera frame.
- Version 1 uses five fields separated by a single `*`, field validation and CRC-32/IEEE.
- Lot prefix is MMYY: month 00–12; year 00 or 21–99.
- JSON contains only `label_version`, `oeps_pn`, `lot` and `quantity`; quantity is a string.
- Per-code 500 ms duplicate suppression and camera disconnect after one minute without clients.
- Compact view, optional preview and diagnostics, plus an in-app reference for label formats.

Test string: `1*OEPSA010123*0926-TRAY-Q5R2*1*D91C90D6`.

## Downloads for developers

**OEPS.Scanner.Client-0.1.0.zip** contains the C#/.NET 10 client DLLs, XML documentation and usage example. Reference both `Scanner.Client.dll` and `Scanner.Contracts.dll`. The two NuGet packages provide the same libraries.

**OEPS.Scanner-0.1.0-win-x64.zip** is the application update package consumed by the launcher. Use the MSI for a fresh installation. SHA-256 sidecars accompany the MSI, application ZIP and SDK ZIP.

Automated checks cover decoding, validation, networking, camera policy, WPF layout and update recovery. Packaged runtime checks and MSI inspection are performed before publication. Installation on a fresh Windows machine and physical camera/print quality are separate operator checks.
