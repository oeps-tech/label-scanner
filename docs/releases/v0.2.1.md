# OEPS Scanner v0.2.1

Improves Bluetooth reader disconnection detection, status display and automatic reconnection.

## Install or update

Download **OEPS.Scanner-0.2.1-setup-win-x64.msi** for a full Windows x64 installation. Existing installations can accept the launcher's update offer. Close both server and test client before updating. Settings are preserved, and both applications display v0.2.1.

## Bluetooth connection monitoring

- Checks Windows' connection status for the selected reader immediately after opening its COM port and every **two seconds** afterward.
- Closes the COM port after **two consecutive disconnected results**, discarding incomplete scans.
- Retries every **five seconds** while a reader client is connected or the debug override is enabled. Retries stop when neither requests the reader.
- Keeps client WebSockets connected throughout reader loss and recovery, so applications resume receiving scans without reconnecting.
- Shows **Connected** only when the COM port is open and Windows confirms Bluetooth connection. Unknown status and a first disconnected observation are displayed explicitly, including after scans or client-count changes.
- Never interprets scan inactivity or serial read timeouts as a Bluetooth disconnection. Serial read errors and closed streams still trigger immediate cleanup.

Monitoring runs off the GUI thread, does not initiate a Bluetooth discovery inquiry, and does not send commands to the reader. Windows can take time to report power loss or loss of range. If no reliable status is available, the application shows **COM open — reader status unknown** and continues reading.

## Compatibility and downloads

Label versions 1/2/3/C/X, JSON fields, WebSocket ports and client DLL APIs are unchanged. Camera readings retain the 500 ms duplicate filter; reader scans have no duplicate suppression. Existing v0.2.0 client integrations remain compatible.

**OEPS.Scanner.Client-0.2.1.zip** contains both .NET 10 client DLLs, documentation and example. The application ZIP is for the automatic updater; use the MSI for a fresh installation. SHA-256 sidecars and the two NuGet packages are also available.

Automated checks cover simulated Bluetooth/serial transitions, native structure layout, real WebSocket recovery, label validation and decoding. The user reported improved reader behaviour. Windows reporting delays and behaviour across adapters still depend on the device and driver; clean-machine installation is a separate operator check.
